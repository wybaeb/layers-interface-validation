# Задания для проверки (учебная синтетика, проект «Пульс», веб-MVP)

Формулировка — на языке цели человека, без слов из дерева. Допустимые конечные ответы зафиксированы до запуска
(кейс «Пульс», артефакт 3.A2, отчёт о проверке дерева, версия «до теста»).

| № | Задание (текст для участника) | Допустимый конечный ответ | Сценарий из User Flow |
|---|---|---|---|
| 1 | Часы с утра предлагают интервалы, а кольцо показывает низкое восстановление. Понять, чему верить | Сегодня → Разбор конфликта | B: единая рекомендация при конфликте |
| 2 | Вы месяц ложитесь до полуночи и хотите проверить, дало ли это эффект | Тренды → Сон | B: тренды как продолжение вердикта |
| 3 | Купили новый браслет и хотите, чтобы сервис учитывал и его тоже | Настройки → Источники данных | A: онбординг и импорт |
| 4 | Ночь была тяжёлая; посоветоваться, стоит ли сегодня бежать длинную | Чат → Диалог с агентом | B: ветка «спросить агента» |
| 5 | Письма от сервиса приходят каждый день, вы хотите получать их раз в неделю | Настройки → Уведомления | A: настройки после онбординга |
| 6 | Понять, за что с вас списали 599 ₽ в этом месяце | Настройки → Подписка «Пульс.Интеллект» | монетизация |

Правило: один заранее известный узел; если допустимых два — оба записаны до теста. Порядок заданий между участниками перемешивается.
